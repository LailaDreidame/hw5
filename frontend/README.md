# Campus Customs desk (React + Vite + TypeScript)

The board for the Campus Customs agent team. From this folder:

```bash
npm install
npm run dev        # http://localhost:5173
```

It talks to the FastAPI backend at `http://localhost:8000` (set `VITE_API_URL` to change it; see `.env.example`). Start the backend first; see the main `README.md`. Design notes are in `../output/design.md`.
